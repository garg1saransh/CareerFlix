# CareerFlix

Replica of the [CareerFlix](https://careerflix.com/) interview and hiring marketing site.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — landing page
- `/login` — employer / candidate role picker
- `/login/employer` and `/login/candidate` — sign in
- `/signup` — 14-day trial
- `/privacy` and `/terms`
